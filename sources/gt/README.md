# Fuentes oficiales de Guatemala

Fecha de consulta inicial: 2026-09-22

El portal de SAT Guatemala es la entrada oficial para confirmar FEL, documentos, normativa, certificadores y versiones. La extracción automática del contenido no fue concluyente; cada documento debe verificarse manualmente antes de incorporarlo.

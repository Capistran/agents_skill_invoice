# Base fiscal de El Salvador

Confirmar con fuentes primarias la autoridad competente, taxonomía de documentos, formato, firma o sello, catálogos, esquemas, estados y ciclo de anulación antes de interpretar un documento.

Separar siempre datos extraídos, validación técnica, regla fiscal, supuestos y revisión humana. Mientras no exista fuente verificada, clasificar el dato como `unknown` y no generar una obligación.

No usar CFDI, RFC, UUID, SAT, PAC, complementos, tipos de comprobante ni reglas de México como equivalentes.

# Brasil (`br`)

Perfil jurisdiccional para análisis y planificación fiscal brasileña. Estado: skills base implementados; las reglas deben separarse por documento y ámbito federal, estadual o municipal.

## Alcance identificado

- NF-e para mercancías;
- NFS-e para servicios;
- CT-e para transporte;
- eventos, autorización, consulta, cancelación y contingencia;
- schemas, notas técnicas, catálogos e impuestos;
- autoridades federales, secretarías de hacienda estatales y municipios.

Las fuentes base están en [sources/br](../../sources/br/README.md). La documentación técnica puede estar en portugués.

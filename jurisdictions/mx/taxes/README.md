# Materias fiscales de México

Índice de análisis fiscal mexicano. Cada materia debe conservar fuente primaria, vigencia, supuestos, casos límite y revisión humana.

- IVA;
- ISR;
- nómina;
- comercio exterior;
- CFDI y obligaciones formales;
- retenciones y regímenes especiales.

No agregar tasas u obligaciones como reglas aplicables sin documento oficial y fecha de vigencia.

# El Salvador (`sv`)

Perfil jurisdiccional para análisis y planificación fiscal de El Salvador. Estado: conocimiento inicial; requiere confirmar fuentes primarias, taxonomía documental, formatos, versiones y servicios antes de proponer reglas.

## Alcance pendiente

- autoridad y normativa aplicable;
- documentos tributarios electrónicos;
- factura electrónica y ciclo de vida;
- impuestos, retenciones y regímenes;
- catálogos, esquemas y firmas;
- anulación, sustitución, consulta y contingencia;
- proveedor o servicio autorizado.

Las fuentes base están en [sources/sv](../../sources/sv/README.md). Los skills `sv-*` describen análisis y planificación, no implementación productiva.

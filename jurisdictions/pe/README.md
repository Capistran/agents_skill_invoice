# Perú (`pe`)

Perfil de análisis y planificación para comprobantes de pago electrónicos peruanos. Estado: alcance identificado; normativa y especificaciones SUNAT pendientes de registro primario.

## Documentos identificados para investigar

- CPE;
- facturas y boletas;
- notas de crédito y débito;
- retenciones y percepciones;
- GRE;
- resúmenes, comunicaciones y CDR;
- PSE y OSE.

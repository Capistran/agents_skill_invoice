# Reglas para Chile

- Usar SII y documentación primaria; EDICOM solo orienta el alcance.
- Diferenciar DTE, CAF, firma XML, folios, guías, notas y exportación.
- Confirmar tipo de documento, schema, ambiente, track ID, aceptación y vigencia.
- No asumir equivalencia con CFDI, PAC o reglas mexicanas.
- Separar emisión, recepción, validación, acuse, rechazo, cesión, archivo y consulta.

# Chile (`cl`)

Perfil de análisis y planificación para DTE chilenos. Estado: alcance identificado; reglas, schemas y documentación SII pendientes de registro primario.

## Documentos identificados para investigar

- facturas y facturas exentas/no afectas;
- facturas de compra y liquidaciones;
- notas de crédito y débito;
- guías de despacho;
- documentos de exportación;
- CAF y representación impresa.

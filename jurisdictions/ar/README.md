# Argentina (`ar`)

Perfil de análisis y planificación para comprobantes electrónicos argentinos. Estado: alcance identificado por referencia secundaria; normativa, servicios, schemas y reglas deben confirmarse con ARCA.

## Documentos identificados para investigar

- comprobantes A, B, C, E y T;
- notas de crédito y débito;
- CAE;
- transporte y COT;
- comprobantes sectoriales.

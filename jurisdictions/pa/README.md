# Panamá (`pa`)

Perfil jurisdiccional para análisis y planificación de factura electrónica y obligaciones fiscales panameñas. Estado: skills base implementados; modalidades, documentos, versiones, servicios y reglas requieren confirmación documental.

## Alcance pendiente

- autoridad y modalidades autorizadas;
- documentos y formatos;
- catálogos y esquemas;
- impuestos, retenciones y cálculos;
- validación, contingencia, anulación y conservación;
- proveedor, certificador o servicio estatal.

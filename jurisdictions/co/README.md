# Colombia (`co`)

Perfil jurisdiccional para análisis y planificación de facturación electrónica y obligaciones fiscales colombianas. Estado: skills base implementados; reglas DIAN, anexos técnicos, catálogos y eventos requieren fuentes primarias verificadas.

## Alcance identificado

- factura electrónica;
- documentos equivalentes;
- notas y documentos relacionados;
- documento soporte y nómina electrónica, si se confirma el alcance;
- proveedor tecnológico y servicios DIAN;
- anexos técnicos, esquemas, catálogos, eventos y contingencia.

Las fuentes base están en [sources/co](../../sources/co/README.md).
